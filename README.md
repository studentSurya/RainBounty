# RainBounty
My first iOS application of the many more to come!

This app integrates iOS Core Location services to identify users' locations and retrieve localized rainfall data through external APIs.
It also uses weather APIs to generate 14-day rainfall forecasts, enabling users to plan rainwater collection activities.
In order to have notifications the app utilizes iOS background fetch and remote notifications with OneSignal to dynamically deliver alerts for upcoming rain events, enabling users to receive timely notifications even when the app is not actively in use.
